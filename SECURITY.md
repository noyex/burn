# Security

Burn reads the access tokens of Claude Code, Codex and Cursor on your Mac, so security reports are taken seriously.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's security advisories](https://github.com/noyex/burn/security/advisories/new).
You'll get an answer within a few days.

## What Burn promises

- Tokens are only read, never refreshed or written, and only sent to the provider they belong to.
- Usage data never leaves your Mac.

Anything that breaks one of these is a vulnerability.
